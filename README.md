# DSH Plugin Manager

Community plugin for [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness) (DSH):
plugin origin classification (official / personal / open-source) and lifecycle
management (hot disable/enable, transactional uninstall) in the web Settings.

> Community project; not affiliated with or endorsed by DeepSeek.

Status: **development skeleton (T01)** — not yet installable end-to-end.
Full bilingual install/security/recovery documentation lands with the beta
release. Compatible with DSH `0.1.1-rc.2` only (see `compatibility.json`).
