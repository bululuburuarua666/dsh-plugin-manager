# DSH 插件管理器

[DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness)（DSH）的社区插件：
插件来源分类（官方 / 个人 / 开源）与生命周期管理（热停用/启用、事务化卸载），
入口在网页端「设置 → 插件」。

> 社区项目，与 DeepSeek 无隶属关系，亦未获其背书。

状态：**开发骨架（T01）** —— 尚未达到可安装状态。
完整的双语安装/安全/恢复文档随 beta 发布提供。仅兼容 DSH `0.1.1-rc.2`
（见 `compatibility.json`）。
